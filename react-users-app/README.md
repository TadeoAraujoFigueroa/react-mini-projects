# UserHub

Aplicación desarrollada en React para gestionar usuarios de forma local.

## Funcionalidades
- Listado de usuarios desde API externa
- Búsqueda en tiempo real
- Crear usuarios
- Editar usuarios
- Eliminar usuarios
- Persistencia con localStorage
- Manejo de loading y errores

## Tecnologías
- React
- Vite
- JavaScript
- CSS
- localStorage
- Fetch API

## Conceptos aplicados
- useState
- useEffect
- Props
- Componentes reutilizables
- Formularios controlados
- Render condicional
- CRUD local
- Persistencia cliente
